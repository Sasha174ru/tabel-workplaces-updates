## Что изменилось в v164

Настройки справочника теперь разделены на три уровня: «Подразделение» → «Участки» → «Рабочие места». На каждом уровне своя кнопка создания: «Создать подразделение», «Создать участок», «Создать рабочее место». Пример: «ЦЕХ 7» → «Печи» → «Печь 41».

Во вкладке «Места» добавлены связанные фильтры «Выбрать подразделение», «Выбрать участок», «Выбрать рабочее место». Они остаются доступны после открытия карточки. Изменение подразделения очищает участок и место; изменение участка очищает место. Новые и удалённые записи сразу отражаются в списках. Пустые дочерние списки недоступны. Выбор места открывает карточку с кнопкой «Добавить»; вместо удалённого места другое автоматически не выбирается.

Существующие печи, РМ, самостоятельное СГП, идентификаторы, нормы, вложенные места и история сохранены. Новые подразделения и участки являются контейнерами, сотрудников добавляют на конкретные рабочие места. Старые данные поддерживаются без пересоздания записей. Восстановление удалённого места с прежним названием в исходном списке возвращает прежний ID; действующие дубли и восстановление в другом разделе запрещены.

Сохранены предыдущие исправления, включая обычный вид смены у пролётчика и подработчика. Состояние фильтров навигационное и не добавляет новых сохранённых полей.

## Обновление

Android APK устанавливается поверх предыдущей версии: не удаляйте приложение и не очищайте его данные.

ПК: «Запуск программы → Настройки → Проверить обновление». Сохраняйте прежний профиль Chrome и локальный адрес.

Настройки справочника: «Настройки → Подразделение → ЦЕХ 7 → Участки → Печи → Рабочие места». Во вкладке «Места» последовательно выберите подразделение, участок и рабочее место. Для передачи изменений справочника нажмите общую кнопку «Сохранить»; на устройствах используйте одинаковую версию приложения.
