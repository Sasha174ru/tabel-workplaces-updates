## Что изменилось в v169

Короткое название для узкой колонки переводного бланка можно настраивать у всех рабочих мест, включая новые, вложенные и восстановленные. Например:

- «Печь 42» → «42»;
- разливочная машина → «РМ»;
- «Ремонтно строительный цех» → «РСЦ»;
- «Цех 5» → «ЦЕХ 5».

В программе остается полное название. В поле переводного бланка попадает только заданное обозначение фактического рабочего места; родительские подразделение и участок не дописываются. Сокращения для новых длинных названий задаются пользователем, приложение не угадывает их.

В «Настройки → Подразделение → подразделение → участок» под каждым рабочим местом есть одно поле «Название в бланках переводов». При вводе показывается предварительный результат. «Применить» сохраняет значение на устройстве; общая кнопка «Сохранить» сверху передает его на другие устройства. Применение одной строки не сбрасывает еще не примененный текст у соседних мест.

«По умолчанию» возвращает прежнее обозначение, например «42» для «Печь 42». У самостоятельных прежних мест поле доступно также в открытом месте. Вложенные места настраиваются независимо. Одинаковые обозначения не объединяют разные рабочие места и их назначения.

Правила включения записей в переводы, часы, разряды, нормы, группировка, сотрудники и история не менялись. Сохранены прежние исправления фильтра «Все», карточек рабочих мест, обычного вида смены у пролётчика и подработчика, иерархии, РМ и СГП.
