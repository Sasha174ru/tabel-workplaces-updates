## Исправления после повторного аудита

- На коротком вертикальном экране Android вся дата календаря становится кнопкой; дневная и ночная смены выбираются крупными кнопками. Весь месяц и «Меню» остаются видимыми.
- Ввод часов согласован с расчётной проверкой: минимум 0,1 часа, шаг 0,1, максимум 12 часов; для ремонта — 11,5. Исторические значения не переписываются.
- Для большой истории добавлено локальное хранилище IndexedDB с безопасным переходом при превышении квоты localStorage. Подтверждение сохранения выдаётся после завершения записи.
- Импорт ожидает резервную запись и сохранение; при ошибке возвращает прежние данные. Одновременный второй импорт не допускается.
- Ускорены статистика и группировка переводов. Результаты на тестовой истории совпали с v179.
- Исправлены подписи подразделений и контекст статистики. Отсутствие настроенных норм отличается от отсутствия смен. Общая инструкция к коротким названиям рабочих мест больше не повторяется под каждой печью.

27 наборов регрессионных проверок, 152 дополнительных проверки, 16 проверок Chrome, Android-сборка и lint прошли. В Chrome 25 000 синтетических записей объёмом 8,3 МБ восстановились после перезагрузки. Подпись APK прежняя; содержимое файлов и SHA-256 проверены. Физический Android ещё не проверен.

Защита, авторизация, облачные разрешения, рабочие данные и настройки подключения не менялись. Старые версии не удаляются.

## Важно при обновлении

Устанавливайте APK поверх прежней версии, без удаления приложения и очистки данных. Перед обновлением рекомендуется экспортировать резервную копию.

**После перехода большой истории на IndexedDB не откатывайтесь на v179 и более старые версии: они не умеют читать новое хранилище.** Экспорт в JSON остаётся доступен.
