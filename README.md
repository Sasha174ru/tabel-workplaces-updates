## Сохранённые возможности

## Добавление работников в режиме «Все участки»

- При выборе подразделения и «Все участки» внизу доступны рабочие места всех его участков и общая сводка смены.
- Нажатие на карточку печи, Разливочных машин или другого места открывает обычную кнопку «Добавить» и форму назначения. После сохранения остаются «Все участки» и остальные карточки.
- В списке рабочих мест доступны «Все» и конкретное место; рядом с названием показан путь участка. Поддержаны новые и вложенные участки, а также прямое назначение по пустому участку или подразделению. Места других подразделений и удалённые места не подмешиваются.
- Исправлена общая сводка для прежнего виртуального подразделения. Проверки разрядов, часов, дублей и специальных ролей не изменены.
- Цельные бланки переводов и ремонта, короткие обозначения и отбор по фактическому месту работы сохранены. Открытие одной карточки не сужает бланк режима «Все участки».


## Разряды

- В настройках появился отдельный пункт «Разряды». Исходный список: 3, 4, 5, 6, 7.
- Можно создавать целые разряды от 1 до 9, удалять их из нового выбора и восстанавливать прежним номером. Дубли и дробные значения не допускаются.
- Справочник используется при приёме и редактировании сотрудников, назначении на смену и настройке норм. Для разливочных машин сохранено ограничение действующими разрядами 3 и 4.
- Удаление не меняет сотрудников, прежние смены, отпуска, статистику, бланки и сохранённые нормы. Имеющихся сотрудников с удалённым разрядом можно найти через фильтр штата.
- Создание и удаление защищены прежним паролем администратора. Нажмите «Сохранить» сверху для передачи справочника остальным устройствам.

## Телефонный справочник

- Добавлены связанные фильтры «Подразделение → Участок → Рабочее место» с выбором «Все». Работают вместе с поиском и бригадой, по штатному месту сотрудника.
- На узком экране телефонное поле занимает всю ширину под именем. Кнопки «Позвонить» и «Копировать» находятся ниже и не сжимают номер.
- В пустом поле уже стоит +7: остаётся ввести номер. Код можно заменить, сохранённые номера автоматически не переписываются.
- Одинокий +7 без номера не сохраняется как контакт, не копируется и не набирается. Счётчик показывает телефоны текущего отбора.

Предыдущие настройки отпусков по участкам, компактные строки сотрудников, цвета спецдолжностей и бланки сохранены.

## Отпуска по подразделениям и участкам

- В графике отпусков добавлены фильтры «Подразделение» и «Участок», общие для вкладок «План» и «Сотрудники».
- Каждый участок распределяется независимо, по штатным рабочим местам сотрудников. Временное направление в смене не меняет участок ежегодного отпуска.
- В «Меню → Настройки → Отпуска» для каждого участка задаётся своё число сотрудников, одновременно находящихся в отпуске. По умолчанию — 5; допустимо целое число от 1 до 999. Лимит применяется отдельно внутри каждой бригады и участка.
- Для подразделения без участков или с непосредственно назначенными сотрудниками предусмотрена отдельная настройка. Новые участки появляются автоматически.
- Изменение лимита защищено прежним паролем администратора. После «Применить» нажмите «Сохранить» сверху для передачи настроек остальным устройствам.
- Уже сохранённые отпуска не пересчитываются автоматически. Новое число используется при следующем распределении и в предварительном расчёте. Отпуска других участков не заменяются при расчёте выбранного участка.
- Правило одного человека на рабочее место, части не менее 14 дней и нормы 35/42 дня сохранены. Независимые изменения настроек двух устройств объединяются без потери других участков.

Узкие строки сотрудников и цветовые обозначения спецдолжностей из предыдущего выпуска сохранены.
