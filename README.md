## Важно при обновлении

Устанавливайте APK поверх прежней версии, без удаления приложения и очистки данных. Перед обновлением рекомендуется экспортировать резервную копию.

После перехода большой истории на IndexedDB не откатывайтесь на v179 и более старые версии: они не умеют читать новое хранилище. Экспорт в JSON остаётся доступен.
