## Что изменилось в v163

Исправлена ошибка восстановления удалённого «СГП» внутри «ЦЕХ 7». Прежнее название в исходном родительском списке возвращает существующее место с прежним идентификатором, настройками, нормами, историей и вложенными местами. Сообщение о дубликате больше не мешает восстановлению архивированного места.

Действующие дубликаты и восстановление в другом родительском разделе по-прежнему запрещены. Потомки, удалённые отдельно, остаются удалёнными.

Все исправления v162 сохранены: полный список активных разделов и вложенных рабочих мест, полные пути, прямой выбор карточки с кнопкой «Добавить», иерархия «ЦЕХ 7», самостоятельное СГП, существующее РМ и обычный вид смены у пролётчика и подработчика. Рабочие места, ID и история не пересоздаются.

## Обновление

Android APK устанавливается поверх предыдущей версии: не удаляйте приложение и не очищайте его данные.

ПК: «Запуск программы → Настройки → Проверить обновление». Сохраняйте прежний профиль Chrome и локальный адрес.

После обновления откройте «Настройки → Рабочие места → ЦЕХ 7 → Создать рабочее место» и введите прежнее название «СГП». Для передачи изменений справочника нажмите общую кнопку «Сохранить»; на всех устройствах используйте одинаковую версию приложения.
