## Обновление

Android APK устанавливается поверх предыдущей версии: не удаляйте приложение и не очищайте его данные.

ПК: «Запуск программы → Настройки → Проверить обновление». Сохраняйте прежний профиль Chrome и локальный адрес, на котором хранятся данные устройства. Для передачи изменений нажмите общую кнопку «Сохранить»; всем начальникам смен рекомендуется одинаковая версия приложения.
