## Добавление сотрудников на пустые участки

- Если у участка нет активных рабочих мест или вложенных участков, сотрудника можно добавить прямо на участок. В «Места» выберите «ЦЕХ 7 → Разливочные машины» и нажмите «Добавить» в карточке.
- Создавать дополнительное рабочее место «РМ» для этого не требуется. Третий фильтр показывает «Учёт по участку».
- Правило действует также для будущих пустых участков. Если внутри появятся настоящие рабочие места, выбираются они; после удаления последнего места снова доступен учёт по участку.
- Используются прежняя форма добавления, проверки часов, повторных назначений, разрядов и норм. Для разливочных машин сохраняются действующие ограничения видов смены.
- В переводных бланках для разливочных машин сохраняется короткое обозначение «РМ». Свои короткие названия продолжают работать без добавления подразделения и полного пути.
- Удалённые дочерние места не восстанавливаются автоматически. Идентификаторы, сотрудники и ранее внесённые смены сохраняются.

## Цвета под каждой спецдолжностью

Подсветка и выбор цвета перенесены внутрь карточки соответствующей спецдолжности, сразу под её названием. Новая спецдолжность получает собственные настройки, а при удалении её карточка исчезает. Выбранный цвет сохраняется, даже если подсветка выключена.
