## Разряды

- В настройках появился отдельный пункт «Разряды». Исходный список: 3, 4, 5, 6, 7.
- Можно создавать целые разряды от 1 до 9, удалять их из нового выбора и восстанавливать прежним номером. Дубли и дробные значения не допускаются.
- Справочник используется при приёме и редактировании сотрудников, назначении на смену и настройке норм. Для разливочных машин сохранено ограничение действующими разрядами 3 и 4.
- Удаление не меняет сотрудников, прежние смены, отпуска, статистику, бланки и сохранённые нормы. Имеющихся сотрудников с удалённым разрядом можно найти через фильтр штата.
- Создание и удаление защищены прежним паролем администратора. Нажмите «Сохранить» сверху для передачи справочника остальным устройствам.
