## Что изменилось в v165

Во вкладке «Места» в списке «Рабочее место» добавлен пункт «Все»: показываются все активные места выбранного участка. Например, для участка «Печи» — печи 41–48.

Выбор конкретного места открывает только его карточку с кнопкой «Добавить» и списком сотрудников. Лента соседних мест и её кнопка «Назад» скрыты. Выбор другого места заменяет карточку; выбор «Все» возвращает общий список. При смене участка прежний выбор сбрасывается. Создание и удаление сразу обновляют списки.

Сохранены подразделения, участки, связанные фильтры, печи, РМ, самостоятельное СГП, нормы, вложенные места и история. «Все» — режим отображения, не запись справочника; он не создаёт новых сохранённых полей. Сохранены предыдущие исправления, включая обычный вид смены у пролётчика и подработчика.

## Обновление

Android APK устанавливается поверх предыдущей версии: не удаляйте приложение и не очищайте его данные.

ПК: «Запуск программы → Настройки → Проверить обновление». Сохраняйте прежний профиль Chrome и локальный адрес.

Настройки справочника: «Настройки → Подразделение → ЦЕХ 7 → Участки → Печи → Рабочие места». Во вкладке «Места» последовательно выберите подразделение, участок и рабочее место либо «Все». Для передачи изменений справочника нажмите общую кнопку «Сохранить»; на устройствах используйте одинаковую версию приложения.
