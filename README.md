## Исправления повторного аудита

- Часы нового назначения проверяются в форме и при сохранении. Обычная смена, «По среднему» и разогрев — не более 12 часов, ремонт — не более 11,5 часа. Сокращённая смена остаётся допустимой. Исторические записи автоматически не обрезаются.
- Для разливочных машин доступны только 3-й и 4-й разряды. Выбор сотрудника с другим штатным разрядом не возвращает недопустимый вариант. Проверка при сохранении действует независимо от ограничения численности. На остальных рабочих местах снова доступны разряды 3–7. Произвольное название «РСЦ» больше не определяется как РМ только по буквам.
- Независимые изменения норм на разных устройствах объединяются по отдельным полям минимума и максимума разряда или спецдолжности. Одновременная правка одного поля сохраняет прежний приоритет явно изменённого локального значения.
- Очищенный телефон не восстанавливается из старого снимка при синхронизации. Очистка сохраняется через поле ввода, общую кнопку «Сохранить», черновик и изменение ключа сотрудника. Сохранена совместимость со старыми снимками.

Сохранены предыдущие функции: добавление сотрудника прямо на пустой участок или подразделение, короткие названия в переводах, фильтры и цвета под каждой спецдолжностью. Код защиты, пароль администратора, подключения и рабочие данные не менялись. Старые версии не удаляются.
