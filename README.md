## Что изменилось в v166

Исправлен режим «Все» во вкладке «Места». Нажатие на карточку «Печь 41» или другого рабочего места открывает её подробности и кнопку «Добавить», но в фильтре остаётся «Все», а остальные карточки сохраняются. Можно переключаться между карточками без потери общего списка; «Добавить» действует только для открытого места.

Выбор конкретного места именно через выпадающий фильтр по-прежнему открывает только его карточку с кнопкой «Добавить» и списком сотрудников. Выбор «Все» возвращает общий обзор участка. Смена подразделения, участка и переход к родителю сбрасывают прежний выбор. Создание и удаление обновляют списки; удаление открытого места в режиме «Все» возвращает общий обзор.

Исправлено открытие карточек с кавычками и HTML-символами в названиях. Сохранены подразделения, участки, связанные фильтры, печи, РМ, самостоятельное СГП, нормы, вложенные места и история. Режим «Все» не создаёт новых сохранённых полей. Сохранены предыдущие исправления, включая обычный вид смены у пролётчика и подработчика.

## Обновление

Android APK устанавливается поверх предыдущей версии: не удаляйте приложение и не очищайте его данные.

ПК: «Запуск программы → Настройки → Проверить обновление». Сохраняйте прежний профиль Chrome и локальный адрес.

Настройки справочника: «Настройки → Подразделение → ЦЕХ 7 → Участки → Печи → Рабочие места». Во вкладке «Места» последовательно выберите подразделение, участок и рабочее место либо «Все». Для передачи изменений справочника нажмите общую кнопку «Сохранить»; на устройствах используйте одинаковую версию приложения.
