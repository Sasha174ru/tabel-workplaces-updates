## Что изменилось в v161

Существующие «Печи», «Разливочные машины» и «СГП» находятся внутри созданного рабочего места «ЦЕХ 7» в настройках и во вкладке «Места». Печи 41–48, РМ и вложенные места сохраняют прежние ID, назначения и нормы. Кнопка «Назад» возвращает к родителю; итоги «ЦЕХ 7» учитывают дочерние разделы. СГП остаётся самостоятельным местом с кнопкой «Добавить».

Если пользовательское «ЦЕХ 7» не создано, обновление не добавляет его автоматически. Другие группы не переносятся. Архивирование родителя скрывает дочерние места из новых назначений, сохраняя историю; явное восстановление возвращает прежние ID.

В фильтре единого штата самостоятельные рабочие места показываются один раз под исходным названием: например, просто «СГП», без дублирования и приписки «— само место». Выбор показывает сотрудников непосредственно этого места; вложенные места выбираются отдельно.

Все исправления v160, включая отображение существующего РМ и обычного вида смены пролётчика/подработчика, сохранены. Пользовательская инструкция обновлена. Заново создавать существующие места не нужно.

## Обновление

Android APK устанавливается поверх предыдущей версии: не удаляйте приложение и не очищайте его данные.

ПК: «Запуск программы → Настройки → Проверить обновление». Сохраняйте прежний профиль Chrome и локальный адрес. Для передачи изменений справочника нажмите общую кнопку «Сохранить»; на всех устройствах используйте одинаковую версию приложения.
