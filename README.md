## Что изменилось в v167

Добавлена отдельная настройка «Название в бланках переводов» для каждого рабочего места. Можно указать «РМ» или другое обозначение, не переименовывая место в программе. Настройка меняет только обозначение места в переводном бланке; сотрудники, назначения, часы, разряды, нормы, группировка и правила переводов сохраняются.

Откройте «Настройки → Подразделение → ЦЕХ 7 → Участок → конкретное рабочее место», затем заполните «Какое название указывать в бланках». У самостоятельного СГП поле доступно сразу в его настройках. Каждое вложенное место настраивается отдельно; название участка не подменяет обозначения всех его мест.

«Применить» сохраняет значение на устройстве. Для передачи другим устройствам нажмите общую кнопку «Сохранить» сверху. «По умолчанию» возвращает прежнее обозначение, например «41» для «Печи 41». Сброс сохраняется при объединении со старым снимком настроек; независимые изменения разных мест объединяются отдельно. Одинаковые обозначения в бланках не объединяют разные рабочие места.

Сохранены предыдущие исправления: режим «Все» не сбрасывается при открытии карточки, выбор конкретного места в фильтре показывает только его карточку, у пролётчика и подработчика обычный вид смены. Иерархия подразделений и участков, РМ, СГП, нормы, история и существующая защита администратора не менялись.
